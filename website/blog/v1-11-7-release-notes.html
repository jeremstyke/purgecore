PurgeCore v1.11.7: A Multi-Color Storage Ring

2026

The Dashboard's ring now matches the category list

The used/free ring on the Dashboard drew a single accent-colored arc for used space, while the storage-by-category list right below it already used a full palette of colors, one per category. The ring now draws one colored arc per category too, each sized to its actual share of the scanned space, so the ring and the list read as one picture instead of two separate ones. The same change shipped on PurgeCore Mobile a little earlier.
