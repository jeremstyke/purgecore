PurgeCore Mobile: Update Notifications, More Color

2026

New: update notifications

An app installed outside Google Play doesn't update itself the way a Play Store app does, there's no background mechanism for that. PurgeCore Mobile now checks GitHub for a newer release each time it opens, and shows a banner at the top of the Storage screen with a direct download link when one is available. Still a manual install either way, but no more remembering to check.

More color, closer to the Windows app

The app leaned mostly on a single accent color beyond the header gradient. Storage now shows used space in teal and free space in violet, the Apps screen has an amber accent, and the "delete all" card in Duplicates has a rose one, the same palette PurgeCore for Windows already uses throughout its sidebar and category bars.
