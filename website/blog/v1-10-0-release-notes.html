PurgeCore v1.10.0: No More Popups Mid-Cleanup

2026

Real bugs from real usage this time, reported and confirmed on an actual Windows machine.

Fixed: a native Windows dialog could interrupt cleanup entirely

Deleting a locked file, a Temp file still open in Edge, for example, could pop up Windows' own "File in use" dialog and stop the cleanup dead until someone clicked something. The recycle-bin deletion API PurgeCore uses has no fully silent mode, so this wasn't a simple settings fix: the app now checks whether a file is locked before attempting to delete it, and skips it quietly if so, the same fix now applies everywhere something gets deleted (Temp files, duplicates, empty folders, browser data).

Fixed: sidebar icons were barely visible

The colored navigation icons introduced a few versions back didn't have enough contrast against the gradient sidebar. They now sit on a solid colored badge with a white icon on top, much easier to tell apart at a glance.

New: "What's new?" link in the update banner

When an update is available, the banner now includes a link straight to that version's release notes, so you can see what's actually changing before deciding to update.

Fixed: about 15 buttons across the app had no styling at all

A handful of buttons, mostly in Explore (Large Files, Folders, Old Files) and a few others scattered around, had never been styled and fell back to Windows' raw default button look: plain white, sharp corners, no color. They now match the rest of the app.

Updated in v1.10.1: Supporters button, NordVPN moved up

Two small additions right after this release: a "Supporters" button next to "Offer a coffee" and "Report a bug" in the sidebar, linking to the Thanks to our supporters page. And the NordVPN recommendation card, previously further down the Dashboard, now sits right after the drive cards so it's visible without scrolling on a smaller screen.
