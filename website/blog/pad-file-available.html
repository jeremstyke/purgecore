PurgeCore Now Has a PAD File

2026

Software directories like Softpedia, MajorGeeks, and FileHippo have long relied on a standard called PAD (Portable Application Description) to list software automatically: one XML file with the app's name, description, category, version, file size, and download links, instead of a human retyping all of it by hand for every submission.

PurgeCore's PAD file is now published and kept current with each release:

View the PAD file

If you run a software directory and want to list PurgeCore, that link has everything needed: description at several lengths, category, current version and file size, and direct download links for both the installer and the portable version.

Not a directory maintainer? This one's mostly for them, but now you know why some download sites might start showing PurgeCore soon.
