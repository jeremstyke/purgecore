PurgeCore v1.11.4: Download Links Fixed

2026

Fixed: download links pointed to the wrong release

PurgeCore Mobile now publishes releases in this same repository. The website's "Download for Windows" button, several blog articles, the PAD file, and the app's own in-app update checker all pointed to "the latest release" rather than a specific version, and GitHub's definition of "latest" doesn't distinguish between the two products sharing this repository. Once a Mobile release shipped after a Windows one, every one of those links quietly pointed at the mobile release instead, with no matching Windows installer to find. Downloads failed, and the app's own update checker reported no update available even when one existed.

Every Windows download link across the site and the app now points to a specific Windows version, never a shared "latest" that mobile releases can also claim.
