PurgeCore v1.9.1 : Des icônes partout

2026

Une passe de polissage visuel : les boutons et liens qui étaient en texte brut ont désormais une icône, comme ceux ("Offrir un café", "Signaler un bug") qui en avaient déjà.

Ce qui a changé

Les boutons de recommandation NordVPN et DeleteMe, Voir le blog, Libérer la RAM, Vider le cache DNS, Windows Update, Rescanner, Nettoyer la sélection, Désinstaller, les boutons de suppression dans Doublons et Dossiers vides, Voir sur GitHub, et le lien du fabricant de chaque pilote ont tous reçu une icône. Rien ne se comporte différemment, c'est purement visuel, destiné à rendre l'interface plus facile à parcourir du regard.

Télécharger v1.9.1

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
