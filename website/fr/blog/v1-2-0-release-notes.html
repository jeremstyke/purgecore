PurgeCore v1.2.0 : Gestionnaire de démarrage

2026

La v1.2.0 ajoute un gestionnaire de démarrage à l'onglet Performance.

Nouveau : gestionnaire de démarrage

À côté de Libérer la RAM dans l'onglet Performance, il y a désormais une liste des applications enregistrées pour se lancer au démarrage de Windows. Chacune a un interrupteur : le désactiver ne désinstalle rien, ça arrête simplement le lancement automatique, et ça peut être réactivé à tout moment. Un bouton "Supprimer" séparé désenregistre une entrée définitivement si vous êtes sûr de ne pas vouloir la revoir.

Seules les entrées de votre propre compte sont affichées (la clé de registre Run et votre dossier Démarrage personnel), rien de partagé à l'échelle du système. Ça permet de fonctionner sans droits administrateur, de façon cohérente avec le reste de l'application.

Vous avez déjà une version antérieure installée ? L'installeur la détecte, ferme l'application en cours d'exécution, installe par-dessus, et la rouvre automatiquement, pas besoin de désinstaller d'abord.

Télécharger v1.2.0

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
