PurgeCore v1.7.1 : Une nouvelle police

2026

Un détail mineur mais qui restait à faire : l'application utilisait la police système par défaut de Windows alors que ce site utilise Inter depuis le début. La v1.7.1 intègre Inter directement dans l'application, les deux partagent désormais la même police et donnent l'impression d'un produit cohérent plutôt que de deux.

Télécharger v1.7.1

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
