PurgeCore v1.11.4 : Liens de téléchargement corrigés

2026

Corrigé : les liens de téléchargement pointaient vers la mauvaise version

PurgeCore Mobile publie désormais ses versions dans ce même dépôt. Le bouton "Download for Windows" du site, plusieurs articles de blog, le fichier PAD, et la vérification de mise à jour intégrée à l'app pointaient tous vers "la dernière version" plutôt qu'une version précise, et la définition de "dernière" par GitHub ne fait pas la distinction entre les deux produits qui partagent ce dépôt. Dès qu'une version mobile sortait après une version Windows, tous ces liens pointaient silencieusement vers la version mobile à la place, sans installeur Windows correspondant à trouver dedans. Les téléchargements échouaient, et la vérification de mise à jour de l'app annonçait qu'aucune mise à jour n'était disponible, même quand une l'était.

Chaque lien de téléchargement Windows du site et de l'app pointe désormais vers une version précise, plus jamais vers une "dernière version" partagée que les versions mobiles peuvent aussi revendiquer.

Télécharger v1.11.4

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
