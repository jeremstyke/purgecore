PurgeCore v1.10.0 : Fini les popups en plein nettoyage

2026

De vrais bugs cette fois, remontés et confirmés sur une vraie machine Windows.

Corrigé : une boîte de dialogue Windows native pouvait interrompre complètement le nettoyage

Supprimer un fichier verrouillé, un fichier temporaire encore ouvert dans Edge, par exemple, pouvait faire apparaître la boîte de dialogue native "Fichier utilisé" de Windows et arrêter net le nettoyage jusqu'à ce que quelqu'un clique sur quelque chose. L'API de suppression vers la Corbeille utilisée par PurgeCore n'a pas de mode totalement silencieux, ce n'était donc pas une simple correction de paramètre : l'application vérifie désormais si un fichier est verrouillé avant de tenter de le supprimer, et l'ignore silencieusement si c'est le cas, la même correction s'applique désormais partout où quelque chose est supprimé (fichiers temporaires, doublons, dossiers vides, données de navigateur).

Corrigé : les icônes de la sidebar étaient à peine visibles

Les icônes de navigation colorées introduites quelques versions plus tôt n'avaient pas assez de contraste face au dégradé de la sidebar. Elles reposent désormais sur un badge coloré uni avec une icône blanche par-dessus, bien plus facile à distinguer en un coup d'œil.

Nouveau : lien "Quoi de neuf ?" dans le bandeau de mise à jour

Quand une mise à jour est disponible, le bandeau inclut désormais un lien direct vers les notes de version de cette version, pour voir ce qui change réellement avant de décider de mettre à jour.

Corrigé : une quinzaine de boutons dans l'application n'avaient aucun style

Une poignée de boutons, principalement dans Explorer (Fichiers volumineux, Dossiers, Anciens fichiers) et quelques autres éparpillés ailleurs, n'avaient jamais été stylés et retombaient sur l'apparence brute par défaut de Windows : blanc uni, coins nets, aucune couleur. Ils correspondent désormais au reste de l'application.

Mis à jour en v1.10.1 : bouton Soutiens, NordVPN remonté

Deux petits ajouts juste après cette version : un bouton "Soutiens" à côté de "Offrir un café" et "Signaler un bug" dans la sidebar, menant vers la page Merci à nos soutiens. Et la carte de recommandation NordVPN, auparavant plus bas sur le Tableau de bord, se trouve désormais juste après les cartes de disques pour rester visible sans défiler sur un petit écran.
