PurgeCore v1.9.0 : Vider le cache DNS

2026

Un petit nouvel outil, et quelques corrections en retard sur la façon dont les outils existants étaient documentés.

Nouveau : Vider le cache DNS

Un bouton "Vider le cache DNS" dans l'onglet Performance, à côté de Libérer la RAM. Il efface les résolutions DNS mises en cache par Windows, ce qui peut aider en cas de pages qui chargent lentement ou échouent à cause d'une entrée obsolète ou incorrecte. Ça ne libère ni espace disque ni mémoire, c'est purement une correction réseau, et ça ne touche rien d'autre sur le système.

Mise en ordre : le site et le README mentionnent désormais Désinstaller

La fonctionnalité Désinstaller (programmes installés, du plus gros au plus petit, retirés via le désinstalleur officiel de chaque programme) était sortie en v1.8.0, mais n'avait jamais été ajoutée à la liste des fonctionnalités sur ce site ni dans le README. Corrigé, les deux la mentionnent désormais correctement.

Télécharger v1.9.0

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
