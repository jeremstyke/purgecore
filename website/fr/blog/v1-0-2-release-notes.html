PurgeCore v1.0.2 : Notifications de mise à jour intégrées

2026

La v1.0.2 est une version courte et ciblée : elle ajoute des notifications de mise à jour directement dans l'application, pour ne plus avoir à vérifier GitHub manuellement.

Nouveau : bandeau de mise à jour

Au lancement, PurgeCore vérifie discrètement si une nouvelle version est sortie. Si c'est le cas, un bandeau apparaît en haut de l'application, sur tous les onglets, avec le numéro de version et deux choix : télécharger et installer immédiatement, ou l'ignorer et continuer avec la version actuelle.

Nouveau : installation en un clic

Choisir de mettre à jour télécharge le nouvel installeur en arrière-plan et le lance directement, sans navigateur, sans étape de téléchargement manuel. L'installeur ferme désormais automatiquement l'application en cours d'exécution, installe par-dessus, et la rouvre une fois terminé, il n'y a rien d'autre à faire.

Pourquoi c'est important

La v1.0.1 avait ajouté une section Nettoyage (doublons, anciens fichiers, dossiers vides, un optimiseur de RAM) et l'export CSV, mais quiconque avait déjà installé la v1.0.0 n'avait aucun moyen de savoir que ces fonctionnalités existaient sans vérifier GitHub. Ceci comble cet écart pour la suite.

Ce qui n'a pas changé

La vérification elle-même ne lit que la liste publique des versions sur GitHub, rien sur vos fichiers, votre disque ou votre usage n'est impliqué ou envoyé où que ce soit. Si GitHub est injoignable, l'application reste silencieuse à ce sujet et fonctionne normalement.

Déjà en v1.0.1 ? La prochaine version après celle-ci s'affichera automatiquement dans un bandeau, pas besoin de revenir vérifier ici manuellement.

Télécharger v1.0.2

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
