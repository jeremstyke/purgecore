PurgeCore v1.11.1 : Un risque de blocage latent corrigé

2026

Une petite correction technique issue d'un audit de code de routine, qui mérite une explication puisque c'est le genre de bug invisible jusqu'à ce qu'il ne le soit plus.

Corrigé : un piège classique .NET dans Santé de la batterie et Vider le cache DNS

Les deux fonctionnalités lancent une courte commande Windows (powercfg pour le rapport de batterie, ipconfig pour le DNS) et capturaient sa sortie, alors que rien dans PurgeCore ne lisait jamais cette sortie. C'est un piège classique : si un processus capturé écrit un jour plus de texte que ce que la petite mémoire tampon interne de Windows peut contenir, il peut se figer complètement, attendant silencieusement que quelqu'un le lise, pendant que PurgeCore attend qu'il se termine. Aucune des deux commandes n'était susceptible d'afficher assez de texte pour déclencher ça, mais c'est un vrai risque qui n'avait pas sa place dans le code. Les deux ne capturent plus une sortie qu'elles n'utilisaient jamais.

Aussi corrigé

Un petit détail de nettoyage mémoire dans la fonctionnalité de liste des soutiens, sans effet visible pour l'utilisateur.
