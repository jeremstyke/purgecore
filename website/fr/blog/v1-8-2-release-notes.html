PurgeCore v1.8.2 : Corrections du gestionnaire de démarrage et de la liste blanche de cookies

2026

Deux bugs réels trouvés lors d'une revue de code, tous les deux corrigés ici.

Corrigé : rebasculer un élément de démarrage deux fois pouvait échouer silencieusement

Désactiver puis réactiver rapidement un raccourci du dossier Démarrage (pas une entrée de registre) pouvait échouer sans aucun message d'erreur, car l'application continuait à utiliser l'ancien emplacement du fichier après qu'il ait déjà physiquement changé. Corrigé en suivant correctement le nouvel emplacement après chaque bascule.

Corrigé : entrées de liste blanche de cookies collées comme URL complètes

Si une entrée de liste blanche était collée comme une URL complète (comme "https://gmail.com") au lieu d'un simple domaine, elle ne correspondait silencieusement à rien dans la base de données de cookies du navigateur et ne protégeait aucun cookie du tout. La liste blanche retire désormais automatiquement le protocole et le chemin, donc coller une URL complète fonctionne comme taper juste le domaine.

Également dans cette version

La nouvelle fonctionnalité Désinstaller (ajoutée en v1.8.0) a reçu une petite correction de sécurité : une entrée de registre au format inhabituel provenant d'un installeur mal formé pouvait auparavant empêcher le chargement de toute la liste de programmes, elle est désormais simplement ignorée individuellement.

Télécharger v1.8.2

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
