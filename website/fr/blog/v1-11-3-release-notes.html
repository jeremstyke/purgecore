PurgeCore v1.11.3 : Corrections des sélecteurs de disque

2026

Corrigé : les listes déroulantes de disque utilisaient le contrôle Windows non stylé

Les sélecteurs de disque dans Doublons, Analyser et le Tableau de bord utilisaient l'apparence brute par défaut du contrôle ComboBox de WPF au lieu d'un style cohérent avec le reste de l'application. Ils utilisent désormais un style dédié, cohérent avec les boutons et cartes de l'application.

Corrigé : les disques sans étiquette de volume s'affichaient "C:\ - C:\"

Le nom du disque et son chemin provenaient de la même valeur Windows sous-jacente sur les disques sans étiquette de volume personnalisée, le plus souvent le disque C:, produisant un affichage redondant. La liste des disques affiche désormais la véritable étiquette de volume quand elle existe, et uniquement le chemin quand ce n'est pas le cas.

Documentation : Santé de la batterie ajoutée au README et au site

La fonctionnalité Santé de la batterie, ajoutée en v1.11.0, était absente de la liste des fonctionnalités du README et du site dans les deux langues, ainsi que du fichier PAD. Les trois la mentionnent désormais.

Télécharger v1.11.3

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
