PurgeCore v1.6.2 : Signaler un bug, plus de couleur

2026

Une version courte centrée sur deux choses : faciliter le signalement d'un problème, et rendre l'interface un peu plus vivante.

Nouveau : Signaler un bug

Un bouton "Signaler un bug" est désormais disponible dans la sidebar et sur la page À propos. Il ouvre directement une nouvelle issue GitHub, pas besoin de chercher dans le dépôt où en déposer une.

Plus de couleur sur le Tableau de bord

La répartition du stockage par catégorie utilise désormais toute la palette de couleurs de l'application (bleu, sarcelle, violet, ambre, rose) au lieu d'un bleu uniforme partout. Plus facile de distinguer les catégories en un coup d'œil.

Un clic plus satisfaisant

Les boutons ont désormais un léger rebond au relâchement du clic, au lieu de revenir à plat instantanément.

Un problème rencontré ? Le nouveau bouton Signaler un bug est le moyen le plus rapide de nous le faire savoir.

Télécharger v1.6.2

Gratuit pour toujours, pas de compte, pas d'essai.

Télécharger pour Windows

Pas encore de certificat de signature de code commercial, donc Windows peut afficher un bref avertissement "éditeur inconnu" au premier lancement. Le code source est public sur GitHub, et chaque version est publiée avec une empreinte SHA-256 vérifiable.
